# Add an identifier to a consignment

Attach reference numbers such as commercial invoice, UCR, or container numbers to a consignment.

## Open the consignment

Click on the relevant consignment in the consignments overview.

![Consignments overview](/img/userGuide/aitac1.png)

## Add the identifier

Click **Add Identifier** on the consignment details page.

![Add identifier button](/img/userGuide/aitac2.png)

Select the identifier type (Commercial Invoice Number, Master Airway Bill Number, UCR Number, Trailer Number, etc.).

![Identifier type selection](/img/userGuide/aitac3.png)

Enter the identifier value (i.e., reference number) for the selected identifier type.

![Identifier value field](/img/userGuide/aitac4.png)

Click **Add Identifier** to finalize.

![Add identifier confirmation](/img/userGuide/aitac5.png)

The added identifier is now viewable on the consignment details page.

![Consignment details with added identifier](/img/userGuide/aitac6.png)
