# IOTA network in the system
##  Role of IOTA network in the System

The role of the IOTA Foundation is to create a Trust Layer for the Internet of Everything (IoE), which enables devices to exchange data and values immutable and free of charge.

![alt text](/img/developerGuide/image-5.png)

## Security, Immutability, and Integrity of the IOTA Ledger

### Security
The IOTA ledger uses a quantum-secure consensus algorithm, which ensures that data stored on the Tangle cannot be forged using brute force attacks.

### Immutability
Multiple independent nodes validate the integrity of the transaction and its data. As more nodes cryptographically verify the data, it becomes increasingly difficult (if not impossible) to alter. Thus, data on the Tangle becomes immutable.

### Integrity
Data integrity is achieved through immutability. This can involve either storing data directly on the ledger or storing a HASH of documents.

### Recommended Resources for Running an IOTA Private Tangle Node
- **4 CPU Cores**
- **16 GB RAM**
- **500 GB SSD disk with good IOPS**

However, it is also possible to run a node with more modest resources.
