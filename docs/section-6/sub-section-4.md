# IOTA Nodes
The IOTA Node provides a trusted, secure and immutable audit trail for the international trade transactions and documents managed by TLIP. If deemed necessary, to preserve data sovereignty, this IOTA Node might not be connected to the main IOTA network, but just to a Local Network devoted to the East Africa region.
The IOTA Node offers a REST API, but all requests must be authenticated by means of JWTs. 
The data stored on the IOTA Node is properly signed and encrypted as per the IOTA Protocol cryptographic suites.
